# D7 storefront demo

เว็บตัวอย่างร้านออนไลน์ D7: หน้าแรก (แบบ E) และหน้าร้าน 14 หน้า เป็นไฟล์ HTML นิ่ง เผยแพร่ด้วย GitHub Pages

- เปิดดู: https://supanya17708.github.io/demo_D7-marketplace-home/
- หน้าร้าน: about, products, product, cart, checkout, login, account, tracking, news, promotions, contact, news-detail, order-result, search
- ตะกร้า ชำระเงิน และข่าวฉบับเต็ม ใช้ดีไซน์แบบที่ 2 (แบ่งซ้ายขวา)
- ข้อความ ราคา และภาพเป็นข้อมูลตัวอย่าง ยังสั่งซื้อจริงไม่ได้

## ระบบหลังบ้าน (Demo)

หน้าตัวอย่างระบบหลังบ้าน 12 หน้า อยู่ในโฟลเดอร์ `admin/` (เปิดที่ `/admin/`) ออกแบบสำหรับจอคอมพิวเตอร์ ข้อมูลทั้งหมดเป็นตัวอย่าง

| ไฟล์ | หน้า |
|---|---|
| admin/index.html | ภาพรวม |
| admin/reports.html | รายงานผู้บริหาร |
| admin/orders.html | ออเดอร์ทุกช่องทาง |
| admin/products.html | สินค้า |
| admin/cms.html | หน้าเว็บ / โปรโมชั่น (CMS) |
| admin/customers.html | ลูกค้า (CRM) |
| admin/inventory.html | คลังสินค้า |
| admin/dispatch.html | จัดส่ง / เขต |
| admin/agents.html | เอเย่นและผลงาน |
| admin/finance.html | บัญชี / กระทบยอด 2C2P |
| admin/channels.html | ช่องทางขาย & ขนส่ง |
| admin/users.html | ผู้ใช้และสิทธิ์ |
